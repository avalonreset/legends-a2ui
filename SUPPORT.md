# Support

## Questions and usage

Start with `README.md`, `docs/AGENT-RECIPE.md`, `wiki/index.md`, and `docs/RELEASE-READINESS.md`. Run `legends-a2ui doctor --json` and `legends-a2ui docs-lookup "<topic>" --live-locations` to inspect local readiness and vendored A2UI specification documentation before opening an issue.

## Bug reports

Open a GitHub issue with the `legends-a2ui` version, OS, Python version, and a minimal synthetic A2UI JSON or JSONL reproduction. Never include credentials, secret tokens, or private infrastructure data.

## Security issues

Do not open public issues for suspected security vulnerabilities. Follow the private reporting instructions in `SECURITY.md`.
